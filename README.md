# Lark Peek

**先偷看一眼，再决定要不要打开。**

周五晚上 23:48，飞书突然冒出一条新消息。它可能是线上告警，也可能只是群里又发了一张猫图。直接点开，会打断手头的事情；完全不看，又难免惦记。

Lark Peek 就是为这个瞬间做的：把鼠标停在飞书会话上，长按 `⌥ Option`，消息会在旁边临时展开。松开按键，预览立即消失。

它不会打开目标会话，也不会主动调用标记已读接口。你可以先了解发生了什么，再决定要不要真正进入会话处理。

## 能做什么

- 悬停预览单聊、群聊和话题消息
- 展示文本、Markdown、互动卡片和消息内图片
- 滚动到顶部继续加载更早消息
- 同名会话只需选择一次，之后自动识别
- 不提供发送、回复、表情或其他写操作

## 下载

从 [GitHub Releases](https://github.com/CBOSSX/lark-peek/releases/latest) 下载 `Lark-Peek-macOS-arm64.zip`。

当前版本支持：

- Apple Silicon Mac
- macOS 14 或更高版本
- 飞书桌面端

这是自签名版本。首次打开时，请在 Finder 中右键 `Lark Peek.app`，选择“打开”；如果仍被拦截，前往“系统设置 → 隐私与安全性”点击“仍要打开”。

## 使用前准备

Lark Peek 通过飞书官方 `lark-cli` 读取消息。请先安装 Node.js 20+，然后执行：

```bash
npx @larksuite/cli@latest install
lark-cli config init
```

启动 Lark Peek 后，从菜单栏选择“授权飞书只读访问…”。应用只会申请当前缺少的
`im:chat:read`、`im:message:readonly` 和 `search:message` 权限，并自动打开飞书授权页面；
确认后会自动完成登录和权限验证，不需要在终端运行 `auth login`。

再按系统提示授予 macOS 辅助功能权限；该权限只用于识别鼠标所在的飞书会话行，不会代替你点击界面。

## 怎么用

1. 把鼠标停在飞书左侧的会话行上。
2. 长按 `⌥ Option` 查看临时预览，松开后关闭。
3. 也可以按 `⌃ Control + ⌥ Option + P` 打开或切换预览。
4. 在消息顶部继续滚动，可以加载更早内容。
5. 按 `Esc` 或点击浮窗外关闭预览。

## 关于“未读”

Lark Peek 的读取链路没有调用标记已读接口，也不会为了预览而打开目标会话。这是它与普通消息客户端最重要的区别。

不过，“任何历史消息读取都永远不会产生服务端已读回执”并不是开放平台提供的长期保证。建议先用测试账号确认它符合你所在组织和当前飞书版本的预期。

消息正文不会落盘；图片只按需下载到临时文件，读入内存后立即删除。同名会话的选择记录只保存匿名界面指纹与 `chat_id` 的本地映射。

## 排查问题

如果长按 `⌥ Option` 没有反应，先把鼠标停在会话名称或头像上，再按一次
`⌃ Control + ⌥ Option + P` 获取明确的识别错误。菜单栏中的“检查辅助功能权限…”会显示当前权限状态，并可直接打开系统设置。

复现问题后，可以在终端导出最近 10 分钟的诊断日志：

```bash
log show --last 10m --info --style compact \
  --predicate 'subsystem == "io.github.cbossx.larkpeek"' \
  > "$HOME/Desktop/LarkPeek-diagnostic.log"
```

日志使用一次性 `triggerID` 串联按键、辅助功能识别、浮窗展示和 `lark-cli` 请求。
会话名、会话和消息标识均由系统隐私机制隐藏或哈希；不会记录消息正文、搜索词、访问令牌、完整命令参数或完整 CLI 输出。
